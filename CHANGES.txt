OZY Admin - Event Creator Modal v2

Changes:
- /event-create opens the native Discord modal immediately.
- Event form includes native category, event channel/location, and publish-channel selectors.
- Event channel can be text, voice, stage, news, thread, forum, or media.
- Publish destination is selected independently and is limited to messageable text/news/thread channels.
- Event description is free-form agenda / previous notes / topics to discuss.
- Verified normal OZY members can create events; Leadership and Special Access remain allowed.
- Users cannot target channels they cannot view.
- Voice/stage selections create native channel-bound Scheduled Events.
- Other channel types create external Discord Scheduled Events pointing to the selected channel.
- Event is published as an OZY event card in the selected publish channel.
- Fixed R+ offset date handling across UTC midnight.

Discord native modal limit:
The first modal uses all 5 available top-level fields, so date/time/duration are completed in a second small modal opened via the Set date & time button.
