# OZY member entry

Discord Community Onboarding owns onboarding and normal member access.

OZY Admin does not check the Total Battle roster, verify names, match names, request leadership approval, gate access, or post verification buttons/cards.

Automatic member lifecycle behavior is intentionally limited to:

1. Join -> themed greeting in `START HERE/#welcome`.
2. Leave -> themed farewell in `START HERE/#goodbye`.

OZY Admin locates the exact `#goodbye` text channel inside the `START HERE` category.

Profile/admin slash commands such as `/game-name`, `/member-name`, `/member-troops`, and `/members-json` remain available, but they are not part of onboarding and never control normal member access.
