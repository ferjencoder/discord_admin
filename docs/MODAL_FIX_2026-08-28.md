# Verification modal production fix

Observed during live join testing:

- New member received the correct Unverified access boundary.
- The welcome message and Verify OZY membership button were posted.
- Clicking the button returned Discord's "The application didn't respond in time".

The verification entry modal is now intentionally implemented with a plain
`discord.ui.TextInput(label=...)` rather than wrapping the input in the newer
`discord.ui.Label` layout component.

The button callback also catches/logs modal-opening failures and returns a
useful ephemeral fallback instead of leaving the interaction unanswered.

This change only affects the initial membership-name form. The post-verification
profile flow remains unchanged.
